## 2. Temuan dan perbaikan

### A1 — nama hidangan panjang keluar kanvas (important, diperbaiki)

`Papeda Ikan Kuah Kuning` (24 karakter) membuat headword 84 px melewati tepi kanvas
**10.77 px**. Ini lolos gate karena `hf check` melaporkannya sebagai `info`
(`canvas_overflow`), bukan `error`/`warning` — artinya video bisa ter-render dengan teks
terpotong tanpa ada yang gagal.

Bukti sebelum: `hf check` → `ℹ canvas_overflow #h1-word > span:nth-of-type(23) … overflowed right 10.77px`.

Perbaikan di `tools/build-dish.py`: ukuran huruf dipilih dari `fit()` — ukuran terbesar
yang masih membungkus ke maksimal dua baris di kolom 888 px (metrik diukur: ~0.52 em per
glyph pada Inter 800, tracking −0.03em). Nama dua baris memakai `.hero.wrap`, hook lockup
turun otomatis (`HOOK_TOP`/`HOOK_RULE_TOP`/`HOOK_SUB_TOP`), nama peta ikut membungkus, dan
kartu akhir memakai ukuran handle sendiri (`HANDLE_SIZE`), bukan ukuran nama hidangan.

Bukti sesudah: 24 karakter → 118 px dua baris, `hf check` 0 layout issue, 48/48 AA; nama 38
karakter → 72 px dua baris, lolos. Regresi dijaga gate baru di `bin/kit-check`.

### A2 — fallback ikon tanpa suara (minor, diperbaiki)

`ikon` yang tidak dikenal (atau kosong) diam-diam memakai `bumbu`. Sekarang menulis
`build-dish: warning: ikon '…' not in tools/icons/, using 'bumbu'` ke stderr. Diuji: 2
peringatan untuk dua ikon buruk.

### A3 — gate baru sempat salah sendiri (minor, diperbaiki)

Versi pertama gate nama panjang memakai `grep -oE '[0-9]+'` yang juga menangkap `1` dari
`h1`, menghasilkan `((: 1 560: syntax error`. Diganti `sed` yang mengambil angka setelah
`top: `. Ini bukti bahwa gate juga perlu diuji negatif, bukan hanya saat hijau.

## 3. Yang diperiksa dan **tidak** bermasalah

- Precedence identitas: `seri`/`handle` dari JSON > path akun > default; diuji dengan JSON
  tanpa kedua field → `Demoakun` / `@demoakun`.
- Validasi builder berjalan **sebelum** menyentuh filesystem: tiga input salah
  (`provinsi_id` asing, 2 fakta, fakta terlalu panjang) → pesan jelas, tidak ada folder
  setengah jadi.
- `--force` wajib untuk proyek yang sudah ada; tanpa itu builder menolak.
- `.hero.wrap`, peta, zoom, dan ping dihitung dari bounding box path provinsi; diperiksa
  untuk Sumatera Barat (tx 70.6), Kalimantan Selatan (−1191.4), Maluku (−2427.4), Bali.
- Atribusi `Peta: geoBoundaries (ODbL)` selalu muncul di kartu akhir (`compositions/end.html`).
- `provinces.json` berisi 34 provinsi; `tools/build-map.py` memaku commit geoBoundaries.

## 4. NOT VERIFIED / risiko yang tersisa

1. **Review independen tidak berjalan.** Delegasi audit keluar sebagai `failed: Request
   timed out`, jadi tidak ada pendapat kedua. Audit ini seluruhnya self-audit dengan bukti
   perintah; tidak ada tanda tangan pihak ketiga.
2. **Metrik lebar huruf adalah perkiraan terukur** (0.52 em), bukan pengukuran font
   sebenarnya. Mitigasi: gate regresi + `hf check` tetap melaporkan `canvas_overflow`
   (sebagai info) sehingga nama yang meleset masih terlihat saat snapshot.
3. `hf preview` dan `hf compare` belum pernah dijalankan di kit ini.
4. Render hanya diverifikasi lokal (2 kali: `…_09-15-13.mp4` dan `…_15-24-46.mp4`);
   `renders/` gitignored, jadi clone bersih tidak membawa bukti video.
5. Peta: 34 provinsi, pemekaran Papua 2022 belum ada di dataset.
6. Metadata GitHub (topics, Release) belum diisi — di luar jangkauan git.

## 5. Kesimpulan

Kit proper untuk dipakai: kedua template lolos gate, builder terverifikasi termasuk kasus
negatif, alur akun dari nol berjalan, dan sesi agen baru langsung tahu status karena
`AGENTS.md` + `HANDOFF.md`. Satu cacat nyata ditemukan (A1) dan sudah diperbaiki beserta
regresinya; tiga cacat dokumen diperbaiki. Tidak ada item "harus segera" yang tersisa di
luar §4.
